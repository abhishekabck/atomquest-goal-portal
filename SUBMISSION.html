Feature Coverage
Goal Setting — Thrust Area, 6 UoM types, weightage validation (total=100%, min 10%, max 8 goals)
Approval Workflow — Submit → Approve / Return for Rework → Goals locked on approval
Quarterly Check-ins — Q1–Q4 per goal, auto progress score per UoM, manager comments
Shared Goals — Manager pushes one goal to multiple employees, check-ins sync automatically
Reports — Excel achievement report (styled, alternating rows) + CSV completion export
Analytics Dashboard — QoQ trend, thrust area donut, UoM bar, completion heatmap, manager effectiveness
Escalation Engine — Configurable rules (goal not submitted, not approved, check-in missed), daily job
Audit Trail — Every state change logged with user, timestamp, old/new value
Performance & Scale Design
ConcernSolution
1,000+ concurrent usersSQLite WAL — multiple readers never block each other; pool_size=20 + max_overflow=40
N+1 query eliminationlazy="joined" on hot ORM relations + explicit joinedload() chains in all dashboard routes
Response payload sizeGZipMiddleware cuts HTML/JSON by ~65% on all responses above 500 bytes
DB cold-start latency64 MB page cache + 256 MB mmap keeps hot pages in RAM between requests
Connection stabilitypool_pre_ping=True + pool_recycle=1800 prevents stale connection errors
